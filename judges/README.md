# Чертежи для проверки

Три настоящих файла, чтобы посмотреть работу программы, не имея своего чертежа.
Открываются на https://aedexa.site — файл остаётся на вашем устройстве, разбор
идёт в браузере.

## Топосъёмка

Режим **DWG-топосъёмка**: рельеф, объекты, 2D-чертёж и 3D-сцена.

- **`topo.dwg`** — квартал ИЖС, 1,9 МБ. Участок 3100 м², 1891 высотная отметка,
  перепад 6,77 м, 21 инженерная сеть, 20 соседних строений. Разбор — 4 секунды.
- **`road.dwg`** — дорожный проект, 20 МБ. Участок 1263 м², 150 сетей.
  Разбор — около двух с половиной минут: файл большой, это нормально.

Оба проходят и через режим **Посадка и отступы** — программа сама узнаёт в них
съёмку участка и считает пятно застройки.

## 2D → 3D

Режим **2D → 3D**: чертёж превращается в объёмную модель.

- **`bridge.dwg`** — мост, 340 КБ. Слоёв участка в нём нет, и программа это
  видит: посадку она на таком чертеже не запускает, а берётся за реконструкцию.

Режим доступен, когда настроен ключ языковой модели.
